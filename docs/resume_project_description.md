# 简历项目描述

## AI 求职助手系统 | Python / Streamlit / LLM API / Pandas

- 构建面向应届生的智能求职 Agent，支持岗位 JD 解析、简历匹配评分、简历定制改写、面试题生成和求职日报生成。
- 设计结构化 Prompt 模板，实现岗位技能抽取、岗位难度评估、应届生适配判断和匹配度评分。
- 支持 CSV 批量导入岗位数据，根据用户简历自动筛选高匹配岗位，并生成每日投递策略。
- 基于大语言模型生成个性化面试题和回答建议，辅助岗位定向面试准备。

## 面试介绍话术

这个项目是我针对自己应届求职场景做的 AI 应用。它可以输入岗位 JD 和个人简历，自动分析岗位要求、计算匹配度、指出简历短板，并生成面试题。技术上我用 Streamlit 做交互界面，Python 拆分核心模块，支持 OpenAI 兼容 API，也做了本地规则 fallback，保证没有 API Key 时也能演示。
